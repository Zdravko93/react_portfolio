## 💻 Installation & Local Setup

If you want to run this project locally, follow these steps:

### React Version (main branch)
```bash
git checkout master
npm install
npm start
```
### TypeScript Version (migration branch)
```bash
git checkout migration/react-to-typescript
npm install
npm start
```

## 🚀 Deployment

The React version is deployed using **GitHub Pages**:

```bash
npm run build
npm run deploy
```

**Note:** The live demo uses the React (master) branch. The TypeScript migration branch is maintained for code reference and local review.
